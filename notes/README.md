# 书籍笔记目录

这个目录存放每本书的章节笔记，当读者在左侧阅读 EPUB 时，右侧会自动显示对应章节的笔记。

## 目录结构

```
notes/
  b1/          ← 日本蜡烛图技术
    index.json ← 章节映射表（EPUB href → 笔记文件）
    cover.md   ← 封面页笔记
    ch01.md    ← 第一章笔记
    ch02.md    ← 第二章笔记
    ...
  b2/          ← 金融市场技术分析
  b3/          ← Al Brooks 价格行为三部曲
  b4/          ← 交易心理分析
```

## 如何添加笔记

### 第一步：找到章节的 href

1. 打开网站，进入书籍阅读模式
2. 打开浏览器控制台（F12）
3. 翻到你想写笔记的章节
4. 控制台会输出类似这样的日志：
   ```
   [EPUB] 当前章节: OEBPS/Text/chapter01.html - 第一章 蜡烛图的起源
   ```
5. 复制 `OEBPS/Text/chapter01.html` 这个 href

### 第二步：创建笔记文件

在对应书的目录下创建 Markdown 文件，比如 `ch01.md`，内容用 Markdown 格式写：

```markdown
# 第一章 蜡烛图的起源

## 核心要点
在这里写下关键知识点...

## 我的理解
用你自己的话解释...

## 实战应用
- 在什么场景下会用到？
- 如何结合实盘观察？
```

### 第三步：更新 index.json

打开对应书的 `index.json`，添加映射：

```json
{
  "OEBPS/Text/chapter01.html": "ch01.md"
}
```

### 第四步：提交到 GitHub

```bash
git add notes/
git commit -m "添加 b1 第一章笔记"
git push origin main
```

页面刷新后，翻到该章节时右侧就会自动显示你的笔记了。

## Markdown 格式说明

支持的 Markdown 语法：
- `# 标题`、`## 二级标题`、`### 三级标题`
- `**粗体**`、`*斜体*`
- `- 列表项`
- `1. 有序列表`
- `> 引用`
- `` `代码` ``
- `---` 分隔线
- `[链接文字](URL)`
